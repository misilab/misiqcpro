# Bienvenue dans MisiQC Pro 🎬

Merci pour votre achat ! Voici comment installer et activer votre licence en quelques minutes.

---

## 1. Installation de MisiQC Pro

### Étape 1 — Télécharger l'application

Le lien de téléchargement de **MisiQC Pro.app** se trouve dans l'email de confirmation Payhip (ou sur la page de téléchargement Payhip).

### Étape 2 — Déplacer dans Applications

1. Ouvrez le fichier **MisiQC-Pro.zip** téléchargé
2. Glissez **MisiQC Pro.app** dans le dossier **Applications** de votre Mac

### Étape 3 — Premier lancement

Au premier lancement, macOS affichera une alerte de sécurité car l'app provient d'un développeur tiers.

**Comment l'ouvrir :**

1. Dans le **Finder**, allez dans le dossier **Applications**
2. **Clic droit** sur **MisiQC Pro** → **Ouvrir**
3. Dans la boîte de dialogue, cliquez à nouveau sur **Ouvrir**

Vous n'aurez à faire cette manipulation qu'une seule fois. Les prochains lancements se feront normalement (double-clic ou icône du Dock).

> *Note : MisiQC Pro est notarisée par Apple — l'alerte n'apparaît qu'au premier lancement.*

---

## 2. Activer votre licence

Votre **clé de licence à vie** vous a été envoyée par email après votre achat sur Payhip. Elle ressemble à :

```
XXXXX-XXXXX-XXXXX-XXXXX-XXXXX-…-XXXXX
```

### Procédure d'activation

1. Lancez **MisiQC Pro**
2. Menu **MisiQC Pro → Réglages…** (ou ⌘ ,)
3. Cliquez sur l'onglet **🔑 Licence**
4. Collez votre clé dans le champ **Clé reçue par email**
5. Cliquez sur **Activer**

✅ Vous devriez voir le message : *"Merci ! Licence valide à vie."*

Le bandeau d'essai disparaît automatiquement et toutes les fonctionnalités d'export (PDF, CSV, guide de correction) sont débloquées.

---

## 3. Important à savoir

- **Licence à vie** : votre clé n'expire jamais. Vous bénéficiez aussi des mises à jour gratuites.
- **Multi-Mac** : votre licence est valable sur tous vos Macs personnels (poste fixe + portable par exemple).
- **Sauvegarde de la clé** : la clé est stockée de manière sécurisée dans votre Trousseau macOS. Si vous changez de Mac, gardez précieusement l'email Payhip pour la réactiver.
- **Anti-piratage** : pour des raisons de traçabilité, le nom de votre Mac et les 5 premiers caractères de votre clé sont affichés discrètement en pied de page des rapports PDF générés.

## 4. Mises à jour

MisiQC Pro vérifie automatiquement les mises à jour au lancement. Vous pouvez aussi forcer la vérification via :

**Menu MisiQC Pro → Vérifier les mises à jour…**

Les mises à jour sont incluses gratuitement avec votre licence à vie.
